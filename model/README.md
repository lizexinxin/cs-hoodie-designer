# 模型插槽

把卫衣 3D 模型文件放進本文件夹（支持以下名字，按顺序自动探测）：

- `hoodie.glb`（推荐，单文件）
- `hoodie.gltf`（带同名的 .bin 和贴图文件）
- `scene.gltf`（Sketchfab 下载解压后的默认名，把整个压缩包内容都放进来）

放好后刷新页面，设计器会自动切换到**真实模型模式**（贴花印花系统）；
删掉模型文件则回到内置程序化模型。

## 哪里找免费模型

- Sketchfab（推荐）：注册免费账号 → 搜索 "hoodie" → 筛选 Downloadable → 下载 GLTF/GLB 格式
- 注意选择 **T 恤/卫衣单品模型**（不是穿着衣服的全身角色），白灰底色最佳
- 各战队 logo 为其商标，仅供个人定制自穿参考，请勿商用
